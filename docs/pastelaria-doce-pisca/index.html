Proposta para Pastelaria Doce Pisca

Esta página foi feita de propósito para Pastelaria Doce Pisca por João Machado, programador web aqui de Guimarães. Inclui:

  • Página rápida no telemóvel, com o vosso nome e cores
  • Ementa/produtos e preços fáceis de atualizar
  • Botões para ligar, WhatsApp e mapa
  • Pedidos de reserva/encomenda directos para o WhatsApp
  • Domínio próprio (ex.: docepisca.pt) ligado ao Google Maps

Eu trato do alojamento e da manutenção. Sem compromisso.
