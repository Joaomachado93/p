Esta página foi feita de propósito para Restaurante Xiquinho por João Machado, programador web aqui de Guimarães. Inclui:

  • Página rápida no telemóvel, com o vosso nome e cores

  • Pedidos de reserva/encomenda directos para o WhatsApp
